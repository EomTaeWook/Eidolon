# Eidolon 사용법

[English overview](../README.en.md) · [다운로드와 제품 소개](../README.md)

이미지 생성·편집부터 결과 관리, 스프라이트·사면도 제작과 LoRA 학습까지 한곳에서 진행합니다. 앱의 **사용법** 화면에서도 한국어·영어 안내와 해당 작업 화면으로 이동하는 버튼을 제공합니다.

## 처음 시작하기

1. Windows x64 릴리스의 EXE를 실행합니다. .NET 런타임은 포함되어 있습니다.
2. **생성 환경 → 생성 방식·지침**에서 ComfyUI 또는 Codex를 선택합니다.
3. 사용할 생성 방식을 아래 안내에 따라 준비합니다.
4. 공통 생성 지침·제외할 요소와 프리셋을 정하고 **생성 환경 저장**을 누릅니다.

### Codex 준비

설치된 Codex에서 먼저 로그인하세요. 앱은 기존 로그인을 사용하며 인증 정보를 설정에 복사하지 않습니다.

실행 모델은 가져온 목록에서 선택합니다. **Codex 기본 모델**은 CLI 기본값을 사용하며 이 항목은 이미지 요청을 처리하는 실행 모델입니다. 내장 이미지 생성 모델을 직접 고르는 설정과는 구분합니다. 실행 파일을 찾지 못하면 `codex.exe`를 선택하고 목록을 새로고침하세요.

Codex는 ComfyUI 엔진이나 체크포인트 설치 없이 사용합니다. 공통 지침·제외할 요소와 참고 이미지를 전달하며 계정의 이미지 생성 지원과 사용 한도가 적용됩니다. 로컬 LoRA·시드·변경 강도는 사용하지 않습니다.

### ComfyUI 준비

1. **설정 → 엔진 설치·연결**에서 설치 경로를 정하고 엔진을 설치합니다.
2. **생성 환경 → 모델·LoRA**에서 모델을 설치하거나 **모델 폴더**·**LoRA 폴더**에 `.safetensors`를 넣고 새로고침합니다.
3. 서버 주소를 입력해 기존 ComfyUI에 연결하거나 설치한 로컬 엔진을 실행합니다. 기본 주소는 `http://127.0.0.1:8189`입니다.

설치에는 인터넷 연결과 여러 GB의 여유 공간이 필요합니다. NVIDIA GPU가 없으면 CPU 환경에서 이미지 생성만 지원합니다. 설치 옵션을 바꾸면 설치·복구를 다시 실행하세요. 앱이 시작한 서버는 앱 종료 시 함께 종료하고 기존 서버는 유지합니다.

## 이미지 생성

1. **이미지 생성**에서 만들고 싶은 대상을 설명합니다.
2. ComfyUI는 모델과 호환 LoRA를 선택합니다. LoRA의 저장된 트리거는 자동으로 추가합니다. Codex는 저장한 실행 모델을 사용합니다.
3. 필요한 경우 참고 이미지를 추가하거나 **배경 투명하게**를 켭니다.
4. 생성 요청을 추가합니다. 실행 중에도 다음 설명을 작성하고 요청을 넣을 수 있습니다.

참고 이미지를 제거하면 설명만으로 생성합니다. 배경 투명 옵션은 ComfyUI에서 생성 후 배경 제거를 수행하고 Codex에서 투명 PNG 생성을 요청합니다.

공통 생성 지침과 제외할 요소는 **생성 환경**에서 저장합니다. 새 요청부터 적용하며 이미 대기 중인 요청은 추가할 때의 설정을 유지합니다.

## 이미지 편집

1. **이미지 편집**에서 원본 이미지를 선택하거나 **생성 결과 → 이 이미지로 편집**으로 가져옵니다.
2. 바꾸고 싶은 그림체나 내용을 설명합니다.
3. ComfyUI는 변경 강도를 확인하고 편집 요청을 추가합니다. 낮은 강도는 원본을 더 유지하고 높은 강도는 수정 설명을 더 반영합니다.
4. 결과를 확인합니다. 결과는 새 파일로 저장하며 원본 이미지는 보존합니다.

Codex에는 원본과 수정 설명을 함께 전달하며 로컬 모델·LoRA·변경 강도는 적용하지 않습니다.

## 생성 결과 관리

**생성 결과**에서 이미지를 선택하면 저장된 프롬프트·모델·시드·해상도와 생성 조건을 확인할 수 있습니다. 프롬프트 JSON이 없어도 이미지는 볼 수 있지만 생성 조건 재사용은 제한됩니다.

- **저장**: 선택 이미지를 원하는 경로로 내보냅니다.
- **프롬프트 재사용**: 설명과 저장된 생성 조건을 다시 가져옵니다. 공통 생성 지침은 현재 설정을 유지합니다.
- **이 이미지로 편집**: 편집 화면에 선택 이미지를 불러옵니다.
- **이 결과로 학습**: 이미지 한 장과 설명을 학습 입력으로 가져옵니다.
- **에셋 제작**: 큰 이미지의 우클릭 메뉴에서 기준 이미지와 설명을 가져옵니다.

Ctrl·Shift로 여러 이미지를 선택해 삭제할 수 있습니다. 이미지 삭제는 PNG와 같은 이름의 프롬프트 JSON을 함께 삭제하며 원본 Job은 보존합니다. **이미지 폴더 열기**로 실제 저장 위치를 확인하세요.

## 스프라이트·사면도 제작

1. **에셋 제작**에서 기준 이미지와 대상 설명을 입력합니다.
2. 스프라이트는 동작·프레임 수·재생 속도를 정합니다. 사면도는 정면·측면·후면·윗면을 만듭니다.
3. 생성된 프레임을 재생·비교하고 필요한 항목만 재생성하거나 교체합니다. 스프라이트는 순서도 바꿀 수 있습니다.
4. 개별 PNG·시트·좌표·기준점·FPS JSON과 원본 사본을 내보냅니다.

재생 속도는 초당 보여주는 프레임 수입니다. 프레임 8장을 8 FPS로 재생하면 한 순환에 1초가 걸립니다. 미리보기와 내보내기는 같은 크기 보정을 사용합니다.

미완성 묶음은 저장한 생성 방식과 설정으로 이어 만들 수 있습니다. **묶음 삭제**는 제작 기록과 내부 작업 파일만 삭제하며 생성 PNG·프롬프트 JSON·원본 생성 작업·내보낸 파일은 보존합니다.

상세 내보내기 계약과 초안 범위는 [에셋 제작](AssetCreation.md)을 참고하세요.

## LoRA 학습

1. **LoRA 학습**에서 학습할 이미지를 흰색·검정색 배경 목록에 추가합니다.
2. 자동 입력된 설명과 이름·트리거를 확인하거나 수정합니다.
3. 학습 설정을 확인하고 필요하면 빠른 학습 옵션을 사용합니다. 기존 LoRA를 선택해 이어 학습할 수도 있습니다.
4. 학습을 시작하고 완료된 LoRA를 이미지 생성에서 선택합니다.

학습에는 앱이 관리하는 로컬 ComfyUI 환경·기반 모델과 NVIDIA GPU가 필요합니다. 학습 설명은 같은 이름의 `.txt`, 이미지 옆 프롬프트 JSON, 공통 설명, 직접 붙인 파일명 순서로 사용합니다. 자동 시각·GUID 이름은 설명에서 제외합니다.

학습 데이터를 `<엔진 설치 경로>/EidolonRuntime/TrainingData/<작업 ID>`에 자동 준비합니다. 원본 이미지와 캡션은 보존합니다. **설정 → 엔진 설치·연결 → 학습 데이터**에서 폴더를 열거나 준비 데이터를 비울 수 있습니다. 완료된 LoRA와 Job 로그는 보존합니다.

이어 학습은 기존 가중치·rank를 불러오며 optimizer·스케줄은 새로 시작합니다. 원본 LoRA를 보존하고 결과를 새 파일로 등록합니다.

## 설정과 저장 위치

**설정 → 일반**에서 이미지 저장 폴더·언어·테마와 MCP 연결을 관리합니다. 이미지 저장 폴더 변경은 새 결과와 갤러리 조회에 적용하며 기존 이미지를 자동 이동하지 않습니다.

| 위치 | 내용 |
|---|---|
| `%LOCALAPPDATA%\Eidolon\Images` | 기본 결과 폴더. 최종 PNG와 같은 이름의 프롬프트 JSON |
| `%LOCALAPPDATA%\Eidolon\Settings.json` | 생성 환경·저장 경로·언어·테마·연결 설정 |
| `%LOCALAPPDATA%\Eidolon\Jobs\<ID>` | 작업·제작 묶음 기록, 생성 원본과 실행 로그 |
| `<엔진 설치 경로>\EidolonRuntime` | 엔진·모델·설치 로그와 학습 데이터 |
| Codex 홈의 `generated_images\<세션 ID>` | Codex 도구가 처음 생성한 원본 PNG |
| `%LOCALAPPDATA%\Eidolon\Logs\Eidolon.log` | 앱 로그 |

Codex 홈의 기본값은 `%USERPROFILE%\.codex`입니다. 원본은 그대로 두고 앱이 현재 요청의 PNG를 Job 폴더에 복사한 뒤 최종 결과를 이미지 폴더에 저장합니다. 생성 경로가 응답에 없으면 현재 실행 세션 폴더의 PNG 한 장을 확인합니다. 다른 세션의 파일을 가져오지는 않습니다.

## 작업 상태와 문제 해결

요청은 공용 대기열에서 순서대로 실행합니다. 하단은 상태·진행률·학습 예상 남은 시간·대기 건수만 표시합니다. 취소와 대기열 비우기는 해당 화면의 실행 영역에 있습니다. 앱을 종료하면 현재 작업과 대기 요청을 정리하며 대기열은 다음 실행에 복원하지 않습니다.

오류가 발생하면 **설정** 또는 **사용법 → 앱 로그 폴더 열기**에서 `Eidolon.log`를 확인하세요. 엔진 폴더의 `Logs\Install.log`·`Engine.log`, 해당 Job의 `Originals\Codex\Codex.log`와 `Training.log`에도 실행 내용이 남습니다.

설정 파일이 손상되면 기존 파일을 덮어쓰지 않고 오류를 표시합니다. 사용자 데이터 폴더의 같은 이름의 `.bak` 파일을 확인해 복원하세요.

MCP 연결·호출 예시와 Windows 수신 권한 안내는 [MCP 사용법](Mcp.md)을 참고하세요.
