# Eidolon 0.1.0-beta.5

## 한국어

### 다운로드

- Windows x64: [Eidolon-0.1.0-beta.5-win-x64.exe](https://github.com/EomTaeWook/Eidolon/releases/download/v0.1.0-beta.5/Eidolon-0.1.0-beta.5-win-x64.exe)
- .NET 런타임을 포함한 단일 EXE입니다. 이미지 생성·학습 엔진과 모델 가중치는 별도로 준비합니다.

### 주요 변경

- 엔진 설치·연결 화면에서 로컬 프롬프트 변환 모델을 설치합니다. Qwen3-4B-Instruct-2507 Q4_K_M과 공식 llama.cpp Windows x64 CPU 실행기를 사용하며 모델은 약 2.5GB입니다.
- 변환 모델을 설치하면 일반·참고 이미지 생성의 한글·영어 설명을 영문 태그로 자동 정리합니다. 별도 사용 체크박스는 없습니다. 설치 전에는 기존 입력으로 생성합니다.
- 입력칸과 저장된 원문은 유지하고 실제 적용 프롬프트를 따로 기록합니다. LoRA 트리거·공통 생성 지침·제외 지침의 기존 합성 경계를 유지합니다.
- MCP 입력은 자동 변환하지 않습니다. MCP 클라이언트가 영어 프롬프트를 작성하는 기존 흐름을 유지하며 편집·다면도·학습도 자동 변환 대상에서 제외합니다.
- 저장된 엔진 경로에 변환기를 설치하며 변환기 설치만으로 엔진·자산 경로를 바꾸거나 ComfyUI를 재시작하지 않습니다.
- Dignus.Log 3.0.0의 로그 등록 API와 SkiaSharp 4의 이미지 그리기 API에 맞췄습니다. 기존 파일 로그 형식·보관과 종료 처리를 유지합니다.

### 확인한 범위

- 솔루션 Debug·Release 빌드: 경고·오류 0개.
- 실제 모델 다운로드·설치와 한글 3건·영문 1건의 로컬 변환을 확인했습니다. 좌우 관계·제외 조건·트리거 보존 예제를 포함하며 이 PC의 CPU 변환 시간은 요청당 약 8~10초였습니다. 미리 취소된 요청도 확인했습니다.
- 실제 UI에서 체크박스 없는 자동 적용, 미적용 경로 입력과 저장 경로의 분리, 한국어·라이트 및 영어·블랙 화면을 확인했습니다.
- 일반·참고 이미지 생성과 원문·적용 프롬프트·공통 지침·제외 지침의 저장을 확인했습니다. 설치된 모델이 있어도 MCP 생성에서 변환기를 호출하지 않는지 확인했습니다.
- EXE 한 파일과 빈 작업 디렉터리에서 실제 실행해 초기화·엔진/MCP 연결·정상 종료를 확인했습니다.

### 알려진 한계

변환 모델은 CPU와 약 2.5GB의 별도 다운로드를 사용합니다. 번역·태그 선택과 이미지 생성 품질을 보장하지 않으므로 중요한 수량·좌우·제외 조건은 결과에서 확인하세요. 이번 실제 생성 연결은 ComfyUI로 확인했으며 Codex 이미지 생성·LoRA 학습·실제 모델 삭제는 수행하지 않았습니다. 다면도는 기존과 같이 참고 이미지 기반 초안입니다.

## English

### Download

- Windows x64: [Eidolon-0.1.0-beta.5-win-x64.exe](https://github.com/EomTaeWook/Eidolon/releases/download/v0.1.0-beta.5/Eidolon-0.1.0-beta.5-win-x64.exe)
- A single executable including the .NET runtime. Generation/training engines and model weights are prepared separately.

### Highlights

- Install a local prompt-conversion model from Engine setup and connection. It uses Qwen3-4B-Instruct-2507 Q4_K_M and the official llama.cpp Windows x64 CPU runtime; the model download is approximately 2.5GB.
- Once installed, Korean/English descriptions are automatically converted to English tags before standard and reference-image generation. There is no separate enable checkbox. Without the model, generation uses the original input.
- Preserve the visible input and saved original separately from the applied prompt. Existing LoRA triggers, shared generation guidelines and exclusions keep their composition boundaries.
- MCP inputs are not converted automatically: MCP clients continue supplying English prompts. Editing, multiple views and training also retain their existing input paths.
- Install into the saved engine location without changing engine/asset roots or restarting ComfyUI merely to install the converter.
- Adapted to the Dignus.Log 3.0.0 registration API and SkiaSharp 4 drawing API while preserving file-log formats, retention and shutdown handling.

### Validation

- Solution Debug and Release builds completed with zero warnings and errors.
- Downloaded and installed the actual model and converted three Korean examples and one English example, including left/right relationships, exclusions and a trigger token. CPU conversion took about 8–10 seconds per request on this PC. A pre-cancelled request was also checked.
- Checked automatic UI behavior without an enable checkbox, saved versus unapplied engine locations, and Korean/light and English/black rendering.
- Completed standard and reference-image generation with separate original/applied prompts and preserved shared guidelines and exclusions. Checked that MCP generation does not invoke the installed converter.
- Ran the standalone EXE from a folder containing only that file with an empty working directory, and checked initialization, engine/MCP connectivity and clean shutdown.

### Known limitations

The converter uses the CPU and requires a separate download of approximately 2.5GB. Translation, tag selection and image quality are not guaranteed; review important counts, left/right relationships and exclusions. Actual generation integration was checked with ComfyUI. Codex image generation, LoRA training and actual model deletion were not exercised. Multiple views remain reference-based drafts.
