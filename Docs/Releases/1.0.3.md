# Eidolon 1.0.3

## 한국어

배포일: 2026-11-03 (한국 표준시)

### 다운로드

- [Windows x64](https://github.com/EomTaeWook/Eidolon/releases/download/v1.0.3/Eidolon-v1.0.3-win-x64.exe)
- [macOS 14 이상 · Apple Silicon](https://github.com/EomTaeWook/Eidolon/releases/download/v1.0.3/Eidolon-v1.0.3-osx-arm64.app.zip)
- [macOS 14 이상 · Intel](https://github.com/EomTaeWook/Eidolon/releases/download/v1.0.3/Eidolon-v1.0.3-osx-x64.app.zip)

Windows는 EXE를 실행합니다. 맥은 ZIP을 풀고 `Eidolon.app`을 쓰기 가능한 Applications 폴더로 옮긴 뒤 Finder에서 실행합니다. .NET과 UI 리소스는 배포물에 포함됩니다.

### 변경 사항

- macOS ARM64·Intel 앱 번들 배포를 추가했습니다. 최신 앱 아이콘을 맥 ICNS에도 적용합니다.
- DI로 Windows 실행 파일 교체와 macOS 앱 번들 전체 교체를 선택합니다. 버전 조회·다운로드·SHA-256·크기 검증·진행률·취소·정상 종료 승인은 기존 흐름을 공유합니다.
- 맥도 **업데이트 후 재시작**을 누르면 다운로드부터 정상 종료·교체·재시작까지 자동으로 이어집니다. 설치 직전 번들 식별자·버전·아키텍처·링크 여부와 전체 파일 해시를 확인하고 이동·시작 실패 시 원본 복원을 시도합니다.
- 시작 시 자동 조회 한 번과 사용자 실행으로 다운로드·설치를 시작하는 기존 정책을 유지합니다.
- macOS Codex 직접 지정·PATH·Homebrew 실행 파일 탐색과 확장자 없는 파일 선택을 지원합니다.

### 배포 범위와 제한

- Windows 및 macOS ARM64·Intel 자체 포함 배포 파일을 GitHub Actions에서 생성합니다.
- 맥은 Codex 또는 외부 ComfyUI 연결을 사용합니다. 로컬 ComfyUI·LoRA 학습·프롬프트 변환기 설치는 Windows x64/NVIDIA 환경 범위를 유지합니다.
- 맥 배포는 ad-hoc 서명이며 Apple Developer ID 서명·공증은 없습니다. 최초 실행은 macOS 보안 설정에서 사용자 허용이 필요할 수 있습니다.
- 테스트·앱 UI 실행·생성·실제 앱 내 업데이트 교체·복원은 이번 배포에서 실행하지 않았습니다. 패키지 생성과 실행 검증은 구분합니다.
- 업데이트 폴더가 쓰기 가능해야 하며 관리자 권한 요청이나 실행 중인 앱 강제 종료는 하지 않습니다. 새 프로세스의 전체 초기화 성공까지 확인하는 건강 상태 검증은 제공하지 않습니다.

## English

Release date: 2026-11-03 (Korea Standard Time)

### Downloads

- [Windows x64](https://github.com/EomTaeWook/Eidolon/releases/download/v1.0.3/Eidolon-v1.0.3-win-x64.exe)
- [macOS 14+ · Apple Silicon](https://github.com/EomTaeWook/Eidolon/releases/download/v1.0.3/Eidolon-v1.0.3-osx-arm64.app.zip)
- [macOS 14+ · Intel](https://github.com/EomTaeWook/Eidolon/releases/download/v1.0.3/Eidolon-v1.0.3-osx-x64.app.zip)

On Windows, run the EXE. On Mac, extract the ZIP, move `Eidolon.app` to a writable Applications folder, and open it in Finder. The runtime and UI resources are included.

### Changes

- Added macOS ARM64 and Intel app bundles with an ICNS version of the current app icon.
- Selects Windows executable replacement or complete macOS app-bundle replacement through DI. Version checks, downloads, SHA-256 and size verification, progress, cancellation and normal-shutdown authorization share the existing lifecycle.
- On Mac, **Update and restart** automatically continues from download through normal shutdown, replacement and restart. The installer checks bundle identity, version, architecture, links and complete file hashes, and attempts to restore the original bundle if replacement or launch fails.
- Preserves one update check at startup and user-initiated downloads and installation.
- Supports configured, PATH and Homebrew Codex executables on macOS, including files without an extension.

### Scope and limitations

- GitHub Actions produces self-contained packages for Windows and both Mac architectures.
- On Mac, use Codex or an external ComfyUI server. Local ComfyUI, LoRA training and prompt-converter installation remain scoped to Windows x64/NVIDIA environments.
- Mac packages are ad-hoc signed without Apple Developer ID signing or notarization. Initial launch may require approval in macOS security settings.
- No tests, app UI launch, generation, or actual in-app replacement/rollback were performed for this release. Packaging does not establish runtime behavior.
- The installation folder must be writable. The updater does not request elevated privileges or force termination, and successful process launch is not a full startup health check.
