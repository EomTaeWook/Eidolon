# Eidolon 1.0.7

## 한국어

- 3D 모델링 화면에서 별도 Blender 파일의 오브젝트나 컬렉션을 선택해 편집 가능한 복사본으로 가져올 수 있습니다. 부품 원본과 수정 대상 파일은 보존합니다.
- 여러 방향의 참고 이미지에서 윤곽과 색 구간을 추정해 모델링 에이전트에 전달합니다. 키트에 열린 곡면, 굽은 단면, 표면에 붙는 눈·입·장식, GLB에 포함되는 표면 텍스처 제작 기능을 보강했습니다.
- [Blender 비교 스크립트](../Modeling.md)로 기준 모델과 후보를 같은 구도에서 비교할 수 있습니다.

다운로드: [Windows x64](https://github.com/EomTaeWook/Eidolon/releases/download/v1.0.7/Eidolon-v1.0.7-win-x64.exe) · [macOS 14+ Apple Silicon](https://github.com/EomTaeWook/Eidolon/releases/download/v1.0.7/Eidolon-v1.0.7-osx-arm64.app.zip) · [macOS 14+ Intel](https://github.com/EomTaeWook/Eidolon/releases/download/v1.0.7/Eidolon-v1.0.7-osx-x64.app.zip)

Windows는 EXE를 실행하세요. macOS는 ZIP을 풀고 `Eidolon.app`을 Applications 폴더로 옮겨 실행하세요. 별도 .NET 설치는 필요 없습니다. macOS 앱은 임시 서명으로 배포되며 공증되어 있지 않아 처음 열 때 시스템 설정에서 허용이 필요할 수 있습니다.

같은 커밋에서 세 플랫폼 패키지를 빌드하고 SHA-256을 확인합니다. 모델링은 개발 환경에서 Blender와 사면도 예제로 확인했습니다. 배포 파일의 앱 실행, macOS 모델링, 앱 내 업데이트 설치는 별도로 검증하지 않았습니다.

## English

- The 3D Modeling screen can append an object or collection from a separate Blender file as an editable copy. The part library and original scene are preserved.
- The modeling agent receives outline and color-region hints where the reference images support them. The kit adds tools for open curved surfaces, curved cross-sections, surface-fitted facial features and decoration, and textures embedded in GLB exports.
- Use the [Blender comparison script](../Modeling.md) to compare a baseline and a candidate from matching viewpoints.

Downloads: [Windows x64](https://github.com/EomTaeWook/Eidolon/releases/download/v1.0.7/Eidolon-v1.0.7-win-x64.exe) · [macOS 14+ Apple Silicon](https://github.com/EomTaeWook/Eidolon/releases/download/v1.0.7/Eidolon-v1.0.7-osx-arm64.app.zip) · [macOS 14+ Intel](https://github.com/EomTaeWook/Eidolon/releases/download/v1.0.7/Eidolon-v1.0.7-osx-x64.app.zip)

Run the EXE on Windows. On macOS, extract the ZIP, move `Eidolon.app` to Applications, and open it. No separate .NET installation is needed. The macOS app is ad-hoc signed and is not notarized, so macOS may require approval on first launch.

The three packages are built from the same commit and checked against their SHA-256 hashes. Modeling was checked in the development environment with Blender and a four-view example. Launching the published packages, macOS modeling, and in-app update installation were not separately verified.
