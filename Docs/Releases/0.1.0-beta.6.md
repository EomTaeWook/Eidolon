# Eidolon 0.1.0-beta.6

## 한국어

### 다운로드

- Windows x64: [Eidolon-0.1.0-beta.6-win-x64.exe](https://github.com/EomTaeWook/Eidolon/releases/download/v0.1.0-beta.6/Eidolon-0.1.0-beta.6-win-x64.exe)
- .NET 런타임과 UI·문자열·고지를 포함한 단일 EXE입니다. 생성·학습 엔진과 모델 가중치는 별도로 준비합니다.

### 주요 변경

- 상단 탐색, 간결한 도구 모음, 작업 패널과 라이트·블랙 테마를 정리하고 앱 아이콘을 이미지 프레임 심볼로 바꿨습니다.
- 생성 결과는 위에, 프롬프트와 실행 버튼은 아래에 배치합니다. 앱 시작 시 이전 최신 결과를 자동 표시하지 않으며 갤러리의 이미지 선택이 생성 화면의 완료 결과를 바꾸지 않습니다.
- 설치된 로컬 변환 모델을 작은 태그 아이콘 버튼으로 호출하고, 변환 결과를 같은 입력칸에서 확인·수정합니다. 생성은 현재 입력을 사용하며 Codex 방식은 로컬 변환 없이 직접 전달합니다.
- ComfyUI의 MCP 일반·참고 생성과 편집은 설치된 변환 모델로 입력을 대상 이미지 모델의 형식에 맞춰 정리합니다. 변환 모델 설치 전에는 기존 입력을 사용하고 다면도·학습에는 자동 변환을 적용하지 않습니다. 엔진 화면에서 변환 모델을 삭제할 수 있습니다.
- 이미지 편집에 브러시 영역 선택과 부분 고치기를 추가했습니다. 편집 캔버스는 실제 참고 원본을 표시하고 선택 밖은 기존 합성 경로로 보존합니다.
- 대기 목록은 팝업 안에서 스크롤하며, 갤러리 페이지 용량은 화면 크기에 맞춥니다. 결과 탭에서 첫 이미지 클릭 전에도 Ctrl+A로 현재 페이지를 선택할 수 있습니다.
- MCP 모듈을 재사용 가능한 MIT 라이선스의 독립 서브모듈로 분리하고 요청별 컨트롤러와 액터 기반 요청 분배를 연결했습니다.

### 확인한 범위

- 기존 WindowsX64 프로필로 Release·Windows x64 자체 포함 단일 EXE 게시를 완료했습니다.
- 테스트·앱 실행·화면 캡처·실제 변환·생성·부분 편집·학습은 이번 배포 작업에서 수행하지 않았습니다.

### 알려진 한계

이번 화면과 동작 변경은 실행 검증을 마치지 않은 베타입니다. 로컬 변환과 생성·부분 편집의 품질을 보장하지 않으므로 결과를 확인하세요. 변환 모델과 생성·학습 환경은 별도 설치가 필요합니다. 앱 내 자동 업데이트는 정식 릴리스만 조회하므로 이 베타는 위 EXE를 직접 내려받아 실행합니다.

## English

### Download

- Windows x64: [Eidolon-0.1.0-beta.6-win-x64.exe](https://github.com/EomTaeWook/Eidolon/releases/download/v0.1.0-beta.6/Eidolon-0.1.0-beta.6-win-x64.exe)
- A single executable including the .NET runtime, UI libraries, localized resources and notices. Generation/training engines and model weights are prepared separately.

### Highlights

- Updated top navigation, compact toolbars, work panels and light/black themes, with a new image-frame app icon.
- Generated images appear above the prompt and actions. Previous results are no longer loaded automatically at startup, and gallery selection does not replace the Generate screen's completed result.
- Run the installed local converter from a compact tag-icon action, then review and edit its output in the same input field. Generation uses the current input; the Codex backend receives it directly without local conversion.
- For ComfyUI, MCP standard/reference generation and editing can use the installed converter to match the target image model's prompt format. Without the converter, requests retain their original input. Multiple views and training do not apply automatic conversion. The converter can also be removed from Engine settings.
- Added brush-mask selection and partial image editing. The editing canvas displays the actual source image, and the existing compositing path preserves areas outside the selection.
- Pending requests scroll inside a popup, and gallery page capacity adapts to the available space. Ctrl+A selects the current Results page before the first image click.
- Extracted MCP into a reusable, independently MIT-licensed submodule with per-request controllers and actor-based request dispatch.

### Validation

- Completed a Release, self-contained Windows x64 single-file publish with the existing WindowsX64 profile.
- No tests, app launch, screenshots, actual conversion, generation, partial editing or training were performed for this release task.

### Known limitations

These interface and behavior changes have not completed runtime validation and are released as a beta. Review conversion and image-editing results; their quality is not guaranteed. The converter and generation/training environments require separate installation. In-app updates only discover stable releases, so download and run the executable above to install this beta.
