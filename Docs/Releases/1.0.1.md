# Eidolon 1.0.1

## 한국어

배포일: 2026-11-03 (한국 시간)

### 다운로드

- Windows x64: [Eidolon-v1.0.1-win-x64.exe](https://github.com/EomTaeWook/Eidolon/releases/download/v1.0.1/Eidolon-v1.0.1-win-x64.exe)
- .NET 런타임과 UI·문자열·고지를 포함한 단일 EXE입니다. 다운로드한 파일을 실행하면 되며 별도 .NET 설치나 명령줄 실행은 필요 없습니다. 생성·학습 엔진과 모델 가중치는 별도로 준비합니다.

### 이번 변경

- 생성 결과 우측 패널의 파일명을 맨 위로 옮기고 작은 복사 아이콘을 추가했습니다. 선택한 이미지의 확장자를 포함한 파일명만 복사하며, 다면도에서도 선택한 개별 이미지를 대상으로 합니다.
- 설정 화면의 이름 붙은 컨트롤을 초기화하여 설정·엔진·MCP 영역으로 이동할 때 발생하던 종료 오류를 수정했습니다.
- 앱·창·실행 파일 아이콘을 보라색 바탕과 굵은 흰색 이미지 심벌로 바꿨습니다. 제품명·제작자 표식과 그라데이션을 제거하고 SVG·PNG·여러 크기의 ICO를 같은 디자인으로 맞췄습니다.
- 실제 앱에서 생성한 파스텔 이미지를 사용해 사용 화면 21장을 촬영하고 한·영 README와 사용법 문서를 갱신했습니다.
- 이미 게시된 MCP.Core `2222abb`를 연결해 PNG 이미지 응답 지원과 컨트롤러·프로토콜 네임스페이스 동기화를 포함했습니다.

### 확인한 범위

- 기존 WindowsX64 프로필로 Release·Windows x64 자체 포함 단일 EXE를 생성했습니다.
- 이번 릴리스 작업에서는 테스트·앱 실행·추가 화면 캡처·실제 생성·편집·학습·클립보드 복사·MCP 호출·앱 내 업데이트 설치를 실행하지 않았습니다.
- 문서의 사용 화면은 앞선 촬영 작업에서 얻은 자료입니다. 새 아이콘과 파일명 복사 UI의 실행 확인 자료는 아닙니다.

### 알려진 한계

이미지 생성·변환·부분 편집과 다면도의 외형·시점 정확도를 보장하지 않습니다. 다면도는 참고 이미지 기반 초안이며 중요한 형태와 장비 배치는 결과를 확인해야 합니다. 생성 방식에 맞는 엔진·모델 또는 로그인된 Codex 환경이 필요합니다.

## English

Release date: 2026-11-03 (Korea Standard Time)

### Download

- Windows x64: [Eidolon-v1.0.1-win-x64.exe](https://github.com/EomTaeWook/Eidolon/releases/download/v1.0.1/Eidolon-v1.0.1-win-x64.exe)
- A single executable including the .NET runtime, UI libraries, localized resources and notices. Run the downloaded file; no separate .NET installation or command-line launch is required. Generation/training engines and model weights are prepared separately.

### Changes in this release

- Moved the selected result's filename to the top of the right panel and added a small copy icon. It copies the filename including its extension, using the selected individual image for multi-view results.
- Fixed the Settings initialization error that could close the app when navigating to Settings, Engine, or MCP sections.
- Updated app, window, and executable icons to a purple background and a bold white image symbol. Removed product text, the creator mark, and gradients, with matching SVG, PNG, and multi-size ICO assets.
- Replaced documentation images with 21 actual app screenshots using generated pastel images, and updated both READMEs and the user guide.
- Pinned the published MCP.Core commit `2222abb`, including PNG image responses and controller/protocol namespace synchronization.

### Validation

- Produced a Release, self-contained Windows x64 single-file executable using the existing WindowsX64 profile.
- No tests, app launch, additional screenshots, actual generation, editing, training, clipboard copying, MCP calls, or in-app update installation were performed during this release task.
- Documentation screenshots come from the earlier capture task; they do not validate the new icon or filename-copy UI at runtime.

### Known limitations

Image generation, prompt conversion, partial editing, and multi-view appearance or projection accuracy are not guaranteed. Multi-view outputs are reference-based drafts; review important shapes and equipment placement. The selected backend requires its engine/models or an installed, signed-in Codex environment.
