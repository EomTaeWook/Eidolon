### 변경 사항

- 로컬 프롬프트 변환 모델의 지시를 번역과 대상 이미지 모델에 맞는 태그·문장 정리로 제한했습니다. 이미지 분석·설명·일반 질의응답을 맡기지 않으며, 제어 문자와 분석·도구 호출 표시가 포함된 출력은 실패로 처리합니다.
- 생성·편집의 참고 이미지를 선택하면 Codex로 유지할 특징을 읽고, 사용자가 내용을 수정하거나 다시 읽을 수 있도록 연결했습니다. 요청한 변경과 충돌하는 특징은 직접 수정할 수 있습니다.
- 최종 유지 특징은 실제 생성 프롬프트에 전달하며, 원문·설정·마스크와 기존 생성 큐·결과 저장 경로를 유지합니다.
- MCP 생성·편집에 `preservation_prompt`를 추가했습니다. 호출자가 특징을 직접 전달하거나 빈 문자열로 특징 지정을 생략할 수 있습니다.
- MCP에서 sampling 지원을 선언한 호출자의 모델에 특징 판단을 요청합니다. 2026 규격은 MRTR 재요청을, 2025 규격은 초기화된 세션의 POST SSE 요청·응답을 사용합니다. 특징 응답을 받은 뒤 기존 생성 큐에 접수하며 원본·요청·환경·인증·만료 조건을 확인합니다.
- MCP.Core의 호출 문맥·결과와 dual-era 호환 계약, 참고 이미지 편집 및 로컬 변환 문서를 갱신했습니다.

### 배포 범위와 제한

- Windows x64·macOS ARM64·Intel 자체 포함 배포 파일을 같은 소스 커밋에서 GitHub Actions로 생성합니다.
- 테스트·앱 UI 실행·실제 모델 분석·MCP 왕복·앱 내 업데이트 설치는 실행하지 않았습니다. 배포 빌드와 실제 동작 확인은 구분합니다.
- 특징 판단의 정확도와 의미 보존을 보장하지 않습니다. 출력 형식 검사는 모델의 내부 추론을 차단하는 보장이 아닙니다.
- MCP sampling은 2026 규격에서 비권장 상태이며 지원을 선언한 클라이언트에서만 동작합니다. 미지원 클라이언트는 `preservation_prompt`를 직접 전달하세요. 기존 2025 SSE 스트림의 재연결·재전송은 제공하지 않습니다.
- 맥 생성은 Codex 또는 외부 ComfyUI 연결 범위입니다. 로컬 ComfyUI·LoRA 학습·프롬프트 변환기 설치는 Windows x64 환경 범위를 유지합니다.
- 맥 배포는 ad-hoc 서명이며 Apple Developer ID 서명·공증은 없습니다. 최초 실행은 macOS 보안 설정에서 사용자 허용이 필요할 수 있습니다.

On Windows, run the EXE. On Mac, extract the ZIP, move `Eidolon.app` to a writable Applications folder, and open it in Finder. No separate .NET installation is required.

### Changes

- Restricted the local prompt converter's instructions to translation and tag or sentence formatting for the target image model. It is not assigned image analysis, explanations or general Q&A. Output containing control characters or analysis/tool-call markers is rejected.
- Connected Codex-based preservation-feature extraction when a reference image is selected for generation or editing. Users can edit the features or read them again, including removing features that conflict with the requested change.
- Passes the final preservation features into the actual generation prompt while retaining the original input, settings, masks, generation queue and result storage.
- Added `preservation_prompt` to MCP generation and editing. Callers can supply features directly or use an empty string to omit preservation instructions.
- Requests feature identification from the calling client's model when it declares sampling support. The 2026 protocol uses MRTR retries; the 2025 protocol uses POST SSE requests and responses within an initialized session. Generation is queued after the feature response, with source-image, request, environment, authentication and expiry checks.
- Updated MCP.Core tool contexts, results and dual-era compatibility contracts, plus reference-editing and local-conversion documentation.

### Scope and limitations

- GitHub Actions produces self-contained Windows x64, macOS ARM64 and Intel packages from the same source commit.
- No tests, app UI launch, live model analysis, MCP round trips or in-app update installation were performed. Packaging does not establish runtime behavior.
- Feature accuracy and semantic preservation are not guaranteed. Output-format checks do not guarantee that internal model reasoning is disabled.
- MCP sampling is deprecated in the 2026 specification and requires explicit client support. Unsupported clients should supply `preservation_prompt` directly. Legacy SSE stream reconnection and replay are not provided.
- Mac generation uses Codex or an external ComfyUI server. Local ComfyUI, LoRA training and prompt-converter installation remain scoped to Windows x64.
- Mac packages are ad-hoc signed without Apple Developer ID signing or notarization. Initial launch may require approval in macOS security settings.
