- [Windows x64](https://github.com/EomTaeWook/Eidolon/releases/download/v1.0.6/Eidolon-v1.0.6-win-x64.exe)

### 변경 사항

- 3D 모델링 탭에서 참고 이미지 한 장이나 다면도로 모델을 만들고, 기존 Blender 장면을 이어서 수정할 수 있습니다. 작업에는 설치된 Blender와 로그인한 GPT(Codex CLI)를 사용합니다.
- 결과의 실제 삼각형 수를 표시하고, Blender와 GLB 파일을 저장할 수 있습니다. 수정 작업은 원본 파일을 보존합니다. 자동 보정 없이 Blender가 저장한 결과를 바로 표시합니다.
- 얇은 디테일의 표면 맞춤은 처음 배치한 쪽을 기준으로 하며, 같은 대상에 이미 적용한 표면 맞춤을 다시 요청하면 기존 설정을 갱신합니다.
- 모델링 MCP에서 앱의 공용 큐에 작업을 접수하고 요청 ID로 모델 결과를 조회할 수 있습니다.

### 배포 범위와 제한

- Windows x64·macOS ARM64·Intel 자체 포함 패키지는 GitHub Actions에서 같은 소스 커밋으로 생성합니다.
- 앱 UI, Blender 모델링 품질, 실제 MCP 왕복 및 앱 내 업데이트 설치는 실행 검증하지 않았습니다. 패키징 성공이 모델링 품질을 보장하지 않습니다.
- 3D 모델링 실행은 현재 Windows·macOS의 기본 환경에 설치된 GPT(Codex CLI)와 Blender를 사용합니다. WSL 및 Claude는 모델링을 실행하지 않습니다.
- 맥 패키지는 ad-hoc 서명입니다. Apple Developer ID 서명과 공증이 없으므로 최초 실행 때 macOS에서 사용자 허용이 필요할 수 있습니다.

## English

Release date: 2026-11-13 (Korea Standard Time)

### Downloads

- [Windows x64](https://github.com/EomTaeWook/Eidolon/releases/download/v1.0.6/Eidolon-v1.0.6-win-x64.exe)
- [macOS 14+ · Apple Silicon](https://github.com/EomTaeWook/Eidolon/releases/download/v1.0.6/Eidolon-v1.0.6-osx-arm64.app.zip)
- [macOS 14+ · Intel](https://github.com/EomTaeWook/Eidolon/releases/download/v1.0.6/Eidolon-v1.0.6-osx-x64.app.zip)

On Windows, run the EXE. On Mac, extract the ZIP, move `Eidolon.app` to a writable Applications folder, and open it in Finder. No separate .NET installation is required.

### Changes

- The 3D Modeling tab creates models from a single image or multiple views and edits existing Blender scenes. It uses a local Blender installation and a signed-in GPT agent (Codex CLI).
- View the actual triangle count and save Blender and GLB files. Edits preserve the source file. The result is shown after Blender saves it, with no automatic refinement pass.
- Thin details fit to the surface from their initial placement side. Reapplying the fit to the same detail and target updates the existing settings.
- The modeling MCP tools queue jobs through the shared app queue and retrieve results by request ID.

### Scope and limitations

- GitHub Actions builds self-contained Windows x64, macOS ARM64, and macOS Intel packages from the same source commit.
- App UI, Blender modeling quality, live MCP round trips, and in-app update installation were not run. Packaging does not establish modeling quality.
- 3D modeling requires a native GPT agent (Codex CLI) and Blender on Windows or macOS. Modeling does not run through WSL or Claude.
- Mac packages are ad-hoc signed without Apple Developer ID signing or notarization. Initial launch may require user approval in macOS.
