# Eidolon 1.0.8

## 한국어

- 설정 메뉴를 왼쪽에 배치하고 일반, 엔진, MCP 연결, 앱 업데이트를 카드로 정리했습니다. 일반 설정의 저장 버튼은 스크롤과 관계없이 하단에서 찾을 수 있습니다.
- ComfyUI 설치와 연결을 나란히 표시합니다. 공용 설치 경로와 Blender·프롬프트 변환 탭을 구분하고, MCP는 서버 상태와 주소, 앱 업데이트는 현재 버전과 실행 버튼을 묶었습니다.
- 다면도 제작은 별도 아이콘으로 표시합니다. 공용 엔진 설치 경로의 [모델링 노하우 문서](https://github.com/EomTaeWook/Eidolon/blob/v1.0.8/Docs/Modeling.md)는 새 모델링 작업마다 참고 자료로 읽습니다.

다운로드: [Windows x64](https://github.com/EomTaeWook/Eidolon/releases/download/v1.0.8/Eidolon-v1.0.8-win-x64.exe) · [macOS 14+ Apple Silicon](https://github.com/EomTaeWook/Eidolon/releases/download/v1.0.8/Eidolon-v1.0.8-osx-arm64.app.zip) · [macOS 14+ Intel](https://github.com/EomTaeWook/Eidolon/releases/download/v1.0.8/Eidolon-v1.0.8-osx-x64.app.zip)

Windows에서는 EXE를 실행합니다. macOS에서는 ZIP을 풀고 `Eidolon.app`을 Applications 폴더로 옮깁니다. 별도 .NET 설치는 필요 없습니다. macOS 패키지는 공증되지 않아 처음 실행할 때 시스템에서 허용해야 할 수 있습니다.

배포 워크플로는 동일한 소스 커밋에서 세 플랫폼 패키지를 만들고 SHA-256을 기록합니다. 실제 앱 화면, 앱 내 업데이트 설치와 모델링 실행은 별도로 검증하지 않았습니다.

## English

- Settings now has a left navigation menu and cards for General, Engine, MCP connection, and App updates. The General save button stays at the bottom while the form scrolls.
- ComfyUI install and connection options sit side by side. The shared installation path and the Blender and prompt conversion tabs are easier to distinguish. MCP groups server status and address, and App updates groups the current version and update actions.
- Multi-view creation has a distinct icon. New 3D modeling jobs can use [local modeling notes](https://github.com/EomTaeWook/Eidolon/blob/v1.0.8/Docs/Modeling.md) from the shared engine installation folder as reference material.

Downloads: [Windows x64](https://github.com/EomTaeWook/Eidolon/releases/download/v1.0.8/Eidolon-v1.0.8-win-x64.exe) · [macOS 14+ Apple Silicon](https://github.com/EomTaeWook/Eidolon/releases/download/v1.0.8/Eidolon-v1.0.8-osx-arm64.app.zip) · [macOS 14+ Intel](https://github.com/EomTaeWook/Eidolon/releases/download/v1.0.8/Eidolon-v1.0.8-osx-x64.app.zip)

On Windows, run the EXE. On macOS, extract the ZIP and move `Eidolon.app` to Applications. No separate .NET installation is needed. The macOS packages are not notarized, so first launch may require system approval.

The release workflow builds all three platform packages from the same source commit and records their SHA-256 hashes. The app UI, in-app update installation, and modeling were not separately verified.
