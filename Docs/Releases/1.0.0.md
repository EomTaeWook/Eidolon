# Eidolon 1.0.0

## 한국어

배포일: 2026-11-01 (한국 시간)

### 다운로드

- Windows x64: [Eidolon-v1.0.0-win-x64.exe](https://github.com/EomTaeWook/Eidolon/releases/download/v1.0.0/Eidolon-v1.0.0-win-x64.exe)
- .NET 런타임과 UI·문자열·고지를 포함한 단일 EXE입니다. 생성·학습 엔진과 모델 가중치는 별도로 준비합니다.

### 주요 기능

- ComfyUI 또는 설치된 Codex로 설명 기반 생성, 참고 이미지 생성, 그림체 변경과 브러시 영역의 부분 편집을 제공합니다.
- 설치된 로컬 변환 모델로 입력을 대상 이미지 모델의 형식에 맞춰 정리하고 같은 입력칸에서 확인·수정합니다. Codex 방식은 입력을 직접 전달합니다.
- 기준 이미지의 정면·우측·좌측·후면·윗면 초안을 만들고, 비교·선택 재생성·교체와 시트 내보내기를 제공합니다.
- LoRA 학습·이어 학습, 모델·LoRA 설치와 관리, 결과 갤러리·필터·저장·재사용, 독립 MCP 모듈을 통한 연동을 제공합니다.

### 이번 변경

- 새 보라색 인물 실루엣과 공통 제작자 표식을 앱·창·실행 파일 아이콘에 적용했습니다. AppIcon 커밋은 2026-10-31 날짜를 유지합니다.
- 설정을 Bough처럼 업데이트·언어·화면 설정·이미지 저장·엔진·MCP가 이어지는 한 열 화면으로 정리했습니다. 기존 설정 저장·설치·취소와 섹션 바로가기를 유지합니다.
- 정상 초기화 뒤 정식 업데이트 확인만 앱 실행당 한 번 시작합니다. 조회 완료를 기다리지 않으며 다운로드·설치는 기존 사용자 버튼으로만 진행합니다. 업데이트 후 재시작 결과를 표시할 때는 자동 조회를 생략합니다.
- 한국어·영어 README에 생성·편집 예시를 추가했습니다. 예시는 README용 내장 이미지 생성 도구의 결과이며 실행 중인 앱의 검증 자료로 사용하지 않습니다.

### 확인한 범위

- 기존 WindowsX64 프로필로 Release·Windows x64 자체 포함 단일 EXE 게시를 완료했습니다.
- 테스트·앱 실행·화면 캡처·실제 변환·생성·편집·학습 및 앱 내 업데이트 설치는 이번 배포 작업에서 실행하지 않았습니다.

### 알려진 한계

이미지 생성·변환·부분 편집과 다면도의 외형·시점 정확도를 보장하지 않습니다. 다면도는 참고 이미지 기반 초안이며 중요한 형태와 장비 배치는 결과를 확인해야 합니다. 생성 방식에 맞는 엔진·모델 또는 로그인된 Codex 환경이 필요합니다.

## English

Release date: 2026-11-01 (Korea Standard Time)

### Download

- Windows x64: [Eidolon-v1.0.0-win-x64.exe](https://github.com/EomTaeWook/Eidolon/releases/download/v1.0.0/Eidolon-v1.0.0-win-x64.exe)
- A single executable including the .NET runtime, UI libraries, localized resources and notices. Generation/training engines and model weights are prepared separately.

### Features

- Generate from descriptions or reference images, restyle images and edit brush-selected regions with ComfyUI or an installed Codex.
- Use the installed local converter to match the target image model's prompt format, then review and edit the result in the same input field. The Codex backend receives the input directly.
- Create front, right, left, back and top drafts from a reference image, compare results, regenerate or replace selected views and export sheets.
- Train or continue training LoRAs, install and manage models/LoRAs, browse and filter results, save or reuse outputs, and integrate through the independent MCP module.

### Changes in this release

- Applied the new purple silhouette and shared creator mark to the app, window and executable icons. The AppIcon commit retains its 2026-10-31 date.
- Aligned Settings with Bough's single-column sections for updates, language, appearance, image output, engine and MCP. Existing save, install, cancel and section shortcuts are preserved.
- Start one stable-update check after successful initialization without waiting for it to complete. Download and installation remain explicit user actions. Automatic checking is skipped when displaying results after an update restart.
- Added generation/editing examples to both READMEs. These examples were created with the built-in image generation tool for documentation and are not runtime validation of Eidolon.

### Validation

- Completed a Release, self-contained Windows x64 single-file publish with the existing WindowsX64 profile.
- No tests, app launch, screenshots, actual conversion, generation, editing, training or in-app update installation were performed for this release task.

### Known limitations

Image generation, prompt conversion, partial editing and multi-view appearance or projection accuracy are not guaranteed. Multi-view outputs are reference-based drafts; review important shapes and equipment placement. The selected backend requires its engine/models or an installed, signed-in Codex environment.
