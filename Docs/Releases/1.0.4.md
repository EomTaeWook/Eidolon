## 한국어

배포일: 2026-11-06 (한국 표준시)

### 다운로드

- [Windows x64](https://github.com/EomTaeWook/Eidolon/releases/download/v1.0.4/Eidolon-v1.0.4-win-x64.exe)

Windows는 EXE를 실행합니다. 맥은 ZIP을 풀고 `Eidolon.app`을 쓰기 가능한 Applications 폴더로 옮긴 뒤 Finder에서 실행합니다. 별도 .NET 설치는 필요 없습니다.

### 변경 사항

- 결과 갤러리의 이전·다음 버튼과 페이지 번호를 없애고 스크롤로 이어 보는 방식으로 바꿨습니다. 처음 30개를 표시하고 아래쪽에 가까워지면 다음 30개를 추가합니다.
- 추가 로딩 중 기존 카드의 선택·스크롤·우측 이미지와 프롬프트를 유지하고 새 카드의 썸네일만 불러옵니다. 로딩 상태는 갤러리 하단에 표시합니다.
- 필터 변경은 스크롤을 맨 위로 돌려 처음 30개부터 시작합니다. 새로고침은 현재까지 펼친 범위를 다시 읽습니다. Ctrl+A는 현재까지 불러온 카드 전체를 선택합니다.
- 중복 추가를 막고 기존 취소·최신 요청·종료·썸네일 해제 경계를 사용합니다. 조회 오류가 나면 기존 목록을 유지하고 자동 재시도를 멈추며 새로고침으로 다시 시도할 수 있습니다.
- 다면도 묶음의 삭제 제한, 전체 삭제 범위와 Core·MCP의 기존 페이지 조회 계약을 유지합니다.

### 배포 범위와 제한

- Windows x64·macOS ARM64·Intel 자체 포함 배포 파일을 같은 소스 커밋에서 GitHub Actions로 생성합니다.
- 이번 배포에서는 테스트·앱 UI 실행·실제 스크롤·선택·삭제·앱 내 업데이트 설치를 실행하지 않았습니다. 배포 빌드와 실제 동작 확인은 구분합니다.
- 맥 생성은 Codex 또는 외부 ComfyUI 연결 범위입니다. 로컬 ComfyUI·LoRA 학습·프롬프트 변환기 설치는 Windows x64 환경 범위를 유지합니다.
- 맥 배포는 ad-hoc 서명이며 Apple Developer ID 서명·공증은 없습니다. 최초 실행은 macOS 보안 설정에서 사용자 허용이 필요할 수 있습니다.

## English

Release date: 2026-11-06 (Korea Standard Time)

### Downloads

- [Windows x64](https://github.com/EomTaeWook/Eidolon/releases/download/v1.0.4/Eidolon-v1.0.4-win-x64.exe)
- [macOS 14+ · Apple Silicon](https://github.com/EomTaeWook/Eidolon/releases/download/v1.0.4/Eidolon-v1.0.4-osx-arm64.app.zip)
- [macOS 14+ · Intel](https://github.com/EomTaeWook/Eidolon/releases/download/v1.0.4/Eidolon-v1.0.4-osx-x64.app.zip)

On Windows, run the EXE. On Mac, extract the ZIP, move `Eidolon.app` to a writable Applications folder, and open it in Finder. No separate .NET installation is required.

### Changes

- Replaced Previous/Next buttons and page numbers in the results gallery with scrolling. The gallery starts with 30 cards and appends the next 30 near the bottom.
- Preserves existing card selection, scrolling and the right-hand image/prompt while loading additional cards. Only new thumbnails are loaded, with a loading indicator below the gallery.
- Changing the filter returns to the top and the first 30 cards. Refresh reloads the range already opened. Ctrl+A selects all currently loaded cards.
- Prevents duplicate additions and uses the existing cancellation, latest-request, shutdown and thumbnail-disposal boundaries. A loading error keeps existing cards and stops automatic retries; Refresh can retry.
- Preserves multi-view deletion restrictions, delete-all scope and the existing Core/MCP paging contracts.

### Scope and limitations

- GitHub Actions produces self-contained Windows x64, macOS ARM64 and Intel packages from the same source commit.
- No tests, app UI launch, actual scrolling, selection, deletion or in-app update installation were performed for this release. Packaging does not establish runtime behavior.
- Mac generation uses Codex or an external ComfyUI server. Local ComfyUI, LoRA training and prompt-converter installation remain scoped to Windows x64.
- Mac packages are ad-hoc signed without Apple Developer ID signing or notarization. Initial launch may require approval in macOS security settings.
