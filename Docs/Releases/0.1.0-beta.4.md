# Eidolon 0.1.0-beta.4

## 한국어

### 다운로드

- Windows x64: [Eidolon-0.1.0-beta.4-win-x64.exe](https://github.com/EomTaeWook/Eidolon/releases/download/v0.1.0-beta.4/Eidolon-0.1.0-beta.4-win-x64.exe)
- .NET 런타임을 포함한 단일 EXE입니다. 생성·학습 엔진과 모델 가중치는 별도로 준비합니다.

### 주요 변경

- 기준 이미지에서 정면·우측·좌측·후면·윗면의 5방향 다면도를 만듭니다. 기본 출력 크기는 1024px, 기본 시트는 5열이며 기존 3·4방향 묶음의 저장값과 원본 파일은 보존합니다.
- 스프라이트 애니메이션 제작 UI와 `eidolon_create_sprite_animation` MCP 도구를 제거했습니다. `eidolon_create_views`는 5방향을 생성합니다.
- 생성 결과에 다면도 묶음 카드와 전체·일반 이미지·다면도 필터를 추가했습니다. 방향별 최신 이미지를 선택해 미리보기·저장·재사용·편집·학습으로 연결합니다.
- 갤러리 필터의 접힌 선택 문구가 언어 변경 후에도 이전 언어로 남던 문제를 수정했습니다. 한국어·영어 전환 중 필터와 선택 이미지를 유지합니다.
- `eidolon_delete_model` MCP 도구를 추가했습니다. 등록된 로컬 체크포인트·LoRA의 실제 파일을 삭제하며, 해당 파일 삭제에 대한 사용자 명시 승인과 `confirm=true`가 필요합니다.
- 엔진 요청의 입력 고정, 설치 상태 확인의 주입 연결, 미리보기 읽기 취소와 최신 결과 적용, 앱 종료 시 목록 갱신 대기를 정리했습니다.

### 확인한 범위

- Release 빌드 경고·오류 0개, 한국어·영어의 필터 3종 전환 6가지와 선택 유지, 라이트·블랙 및 최소 창 1024×740의 화면을 확인했습니다.
- EXE 한 파일과 빈 작업 디렉터리에서 실제 실행해 초기화·엔진/MCP 연결·정상 종료를 확인했습니다. 실제 모델 삭제와 LoRA 학습은 이번 검증에서 수행하지 않았습니다.

### 알려진 한계

다면도는 참고 이미지 기반 초안입니다. 정밀한 정투영이나 방향 사이의 세부 형태 일치를 보장하지 않으며, 이번 이미지 품질 비교는 Codex 경로로 수행했습니다.

## English

### Download

- Windows x64: [Eidolon-0.1.0-beta.4-win-x64.exe](https://github.com/EomTaeWook/Eidolon/releases/download/v0.1.0-beta.4/Eidolon-0.1.0-beta.4-win-x64.exe)
- A single executable including the .NET runtime. Generation/training engines and model weights are prepared separately.

### Highlights

- Create front, right, left, back and top views from a reference image. The default export size is 1024px with five sheet columns. Existing three/four-view collections retain their saved settings and original files.
- Removed the sprite-animation creation UI and the `eidolon_create_sprite_animation` MCP tool. `eidolon_create_views` now generates five views.
- Added grouped multiple-view cards and All / Images / Multiple views filters to Results. Select the latest image for each direction to preview, save, reuse, edit or use for training.
- Fixed the collapsed gallery filter caption retaining the previous language after a language change. Switching between Korean and English preserves the active filter and selected image.
- Added the `eidolon_delete_model` MCP tool. It permanently deletes a registered local checkpoint or LoRA file and requires explicit user approval for that exact file and `confirm=true`.
- Improved captured engine-request inputs, injected installation checks, preview cancellation and latest-result handling, and waiting for result-list refreshes during shutdown.

### Validation

- Release build completed with zero warnings and errors. Checked all six Korean/English transitions across the three filters, selection preservation, light/black themes and the minimum 1024×740 window.
- Ran the standalone EXE from a folder containing only that file with an empty working directory. Checked initialization, engine/MCP connectivity and clean shutdown. Actual model deletion and LoRA training were not exercised in this validation.

### Known limitations

Multiple views are reference-based drafts. Exact orthographic projection and matching details across views are not guaranteed. Image-quality comparisons for this change used the Codex backend.
