# 에셋 제작 품질 검증

2026-10-12 사용자의 실제 생성 테스트 요청으로 수행한 비교다. 입력 조건·생성 완료·내보내기 성공과 외형·시점·동작 품질을 각각 판정한다. 다른 이미지나 모델 전체에 대한 품질 보증으로 사용하지 않는다.

이 비교 후 사면도 프롬프트를 `Required camera view`와 구체적인 카메라 위치가 맨 앞에 오도록 정리했다. 아래 실제 생성 결과는 이 후속 변경 전 지침의 결과이며, 후속 변경의 빌드·생성 테스트는 수행하지 않았다.

## 환경과 입력

- 로컬 모델: Illustrious-XL-v0.1, SDXL, ComfyUI v0.38.0, RTX 3060 Ti 8 GB.
- 비교 경로: 기본 img2img, IP-Adapter Plus 추가, 기준 이미지 옆 빈 칸 인페인트, 앱의 기존 Codex 내장 이미지 생성.
- 기준 파일은 테스트에서 새로 생성한 파란 갑옷·금색 장비·빨간 망토 캐릭터다. 사용자 사진·첨부를 사용하거나 전송하지 않았다. 기준 이미지 SHA-256은 `F45F6C4A94CC9E16F02D3FD309CB3C64CEFE00B127C97B796993629E96EF5EA3`다.
- 모든 제작 요청의 사용자 `prompt`·`action`·프레임별 포즈 설명을 비웠다. 사면도는 네 시점, 스프라이트는 자동 제자리 걷기 8프레임이다. LoRA는 사용하지 않았다. 공통 지침은 `icon, centered, plain white background`, 제외할 요소는 `low quality`다.
- 로컬 비교의 시드는 482713이다. Codex에는 시드·체크포인트·참고 변경 강도를 적용하지 않는다.
- 생성은 실제 `AssetCreationService → StudioService`를 사용했다. 빈 칸 인페인트와 강화 사면도는 채택 전 비교용 워크플로를 별도 실행했다. UI 앱을 띄워 화면을 조작하는 검증은 수행하지 않았다.

실제 사용자 설정·설치·결과 폴더를 보존하고 `artifacts/quality-tests/20261012` 아래 설정·Job·이미지·로그를 저장했다. ComfyUI는 테스트 전용 8195 포트로 실행하고 종료했다. 테스트 전용 강화 가중치는 해시 확인 후 사용하고 정리했다. 제품 설치에 노드·가중치를 추가하지 않았다.

## 판정 기준

사면도는 대상이 유지되면서 정면·측면·후면·윗면이 구분되어야 한다. 측면이 정면 구도에 머물거나 윗면이 눈높이 구도를 반복하면 실패다. 3D 모델링 참고에 필요한 정확한 90도 투영은 별도로 확인한다.

스프라이트는 발·팔의 연속 동작이 있어야 하며, 같은 자세의 표면 변화만 있으면 실패다. 의상·장비·몸 비율·카메라·발 기준선의 변화와 마지막→첫 프레임 연결도 확인한다. 서로 다른 PNG가 생성된 사실만으로 통과시키지 않는다.

## 변경 판단

IP-Adapter 자동 추가와 같은 캔버스 인페인트는 이 비교에서 연속 동작과 대상 유지가 함께 개선되지 않아 제품 경로에 채택하지 않았다. 기존 ComfyUI 참고 생성과 강도를 보존한다. 이 모델에서 프롬프트만으로 시점·동작을 바꾸는 경로는 품질 기준에 미달한다.

대상·동작 설명을 선택 입력으로 바꾸고 `AssetFramePromptBuilder`에서 네 시점과 시간순 걷기 지침을 구성한다. Codex 비교에서 발견한 손짓 복귀를 줄이기 위해 모든 걷기 단계에 양팔 위치와 낮은 손 위치를 명시하고 장비 유지 지침을 보강한다. 사용자가 직접 입력한 포즈에는 기본 걷기를 섞지 않는다. 정확한 윗면과 안정된 연속 프레임은 모델별 구조·시간축 제어 검증이 남아 있다. 모든 프레임을 한 번에 좋은 결과로 생성하는 기준에는 통과하지 못했다.

## 검증과 로컬 결과

검증 프로그램은 이미지 설명·동작 없는 입력, 네 시점 순서, 2·4·8·16·32프레임의 시간 지침, 고정 시드, 사용자 포즈 유지, 기준 이미지 누락·포즈 수 오류, MCP의 제작 도구 필수 인자를 확인한다. 일반 이미지 생성 도구의 `prompt` 필수 계약을 유지한다. 생성 후 시트·프레임·manifest 내보내기도 실행한다.

전체 솔루션 빌드는 경고·오류 0개로 통과했다. 최종 코드의 입력·MCP 계약 검증도 통과했다. 내보낸 사면도 라벨·시트 크기, 서로 다른 투명 스프라이트 8장, 실제 PNG 알파, 10 FPS·무한 반복 GIF를 검사했다. 이 검사는 기하학·동작 품질 통과를 의미하지 않는다.
