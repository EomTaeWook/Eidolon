# Eidolon

**한국어** | [English](README.en.md)

**Eidolon은 프롬프트로 이미지를 생성·편집하고 게임 에셋과 LoRA를 만드는 데스크톱 앱입니다.**

ComfyUI와 설치된 Codex 중 생성 방식을 선택하고, 공통 생성 지침부터 결과 관리·스프라이트·사면도 제작까지 같은 작업 흐름에서 진행합니다.

## 다운로드

[Eidolon v0.1.0-beta.1 Windows x64 다운로드](https://github.com/EomTaeWook/Eidolon/releases/download/v0.1.0-beta.1/Eidolon-0.1.0-beta.1-win-x64.exe) · [릴리스 정보](https://github.com/EomTaeWook/Eidolon/releases/tag/v0.1.0-beta.1)

단일 `.exe` 파일을 실행하세요. 압축 해제나 별도 .NET 설치는 필요 없습니다. Codex 방식은 설치된 Codex에 먼저 로그인하고, ComfyUI 방식은 앱에서 엔진과 모델을 준비합니다.

## 핵심 경험

- **프롬프트 중심 생성**: 만들고 싶은 대상을 설명하고 참고 이미지를 선택적으로 추가합니다.
- **공통 스타일 적용**: 생성 지침·제외할 요소와 프리셋을 저장해 생성과 편집에 함께 사용합니다.
- **결과에서 다음 작업으로**: 생성 조건을 확인하고 프롬프트 재사용·편집·학습·에셋 제작으로 이어갑니다.
- **게임 에셋 제작**: 기준 이미지로 스프라이트와 정면·측면·후면·윗면 사면도를 만들고 비교·내보냅니다.
- **내 이미지로 학습**: 이미지를 선택하면 학습 데이터를 자동 준비하고 완료된 LoRA를 생성에서 사용합니다.

## 주요 기능

- **이미지 생성·편집**: ComfyUI 또는 Codex, 참고 이미지 생성, 원본 이미지 편집, 투명 배경
- **생성 결과**: PNG 갤러리, 프롬프트·모델·생성 조건 조회, 재사용, 내보내기와 선택 삭제
- **스프라이트·사면도**: 프레임 재생·순서 변경, 개별 재생성·교체, 미완성 이어 만들기, PNG·시트·좌표·FPS JSON 내보내기
- **모델·LoRA**: safetensors 폴더 조회, SD 1.5·SDXL 계열 관리, LoRA 선택과 트리거 자동 적용
- **LoRA 학습**: 학습 데이터 자동 준비, 새 학습·이어 학습, 빠른 학습 설정, 취소와 예상 남은 시간
- **작업 관리**: 공용 대기열, 실행 중 다음 요청 추가, 취소·대기 요청 비우기, 원본과 실행 로그 보존
- **설정·연결**: 한국어·영어, 라이트·블랙 테마, 저장 폴더, 외부 ComfyUI 서버와 MCP

스프라이트와 사면도는 참고 이미지 기반 초안입니다. 생성된 동작·외형·시점은 사용 목적에 맞게 검토하세요. 현재 배포 대상은 Windows x64입니다.

## 실행

### 배포 파일 실행

1. 릴리스의 Windows x64 EXE를 원하는 폴더에 저장하고 실행합니다.
2. **생성 환경 → 생성 방식·지침**에서 ComfyUI 또는 Codex를 선택합니다.
3. Codex는 설치된 Codex에서 먼저 로그인합니다. 실행 모델은 가져온 목록에서 선택하며 기본 모델 항목은 CLI 기본값을 사용합니다. 실행 파일을 찾지 못하면 `codex.exe` 경로를 선택하세요.
4. ComfyUI는 **설정 → 엔진 설치·연결**에서 엔진을 준비합니다. **생성 환경 → 모델·LoRA**에서 모델을 설치하거나 모델 폴더·LoRA 폴더에 `.safetensors` 파일을 넣고 새로고침합니다.
5. 공통 생성 지침과 제외할 요소를 정한 뒤 **생성 환경 저장**을 누릅니다. **이미지 생성**에서 설명을 입력해 요청을 추가하세요.

설정과 작업 데이터는 `%LOCALAPPDATA%\Eidolon`에 저장합니다. 앱을 업데이트할 때 실행 파일을 교체해도 이 데이터는 유지됩니다.

### 이미지와 에셋 작업

**이미지 편집**은 원본과 수정 설명을 받아 결과를 새 이미지로 저장합니다. **생성 결과**에서는 프롬프트 재사용·편집·학습으로 이어가거나 큰 이미지를 우클릭해 에셋 제작 입력을 가져옵니다.

**에셋 제작**에서는 스프라이트의 동작·프레임 수·재생 속도를 정하거나 정면·측면·후면·윗면 사면도를 만듭니다. 미리보기와 내보내기는 같은 크기 보정을 사용합니다. 묶음 삭제는 제작 기록과 내부 작업 파일을 지우며 생성 PNG·프롬프트 JSON·내보낸 파일은 보존합니다.

**LoRA 학습**은 이미지 선택, 이름·트리거 확인, 학습 설정 순서로 진행합니다. 로컬 ComfyUI 환경·기반 모델과 NVIDIA GPU가 필요하며 완료된 LoRA의 트리거는 생성 시 자동 적용합니다. Codex 생성에는 로컬 모델·LoRA·시드·변경 강도를 적용하지 않습니다.

단계별 안내, 저장 위치와 문제 해결은 [사용법](Docs/Usage.md), 제작·내보내기 계약은 [에셋 제작](Docs/AssetCreation.md)에 정리했습니다.

### 소스에서 실행

개발 실행에는 .NET 10 SDK가 필요합니다. 저장소 루트에서 실행합니다.

```powershell
dotnet run --project Eidolon.App/Eidolon.App.csproj
```

## MCP 연결

**설정 → 일반 → MCP 연결**에서 서버를 켜고 `http://127.0.0.1:8190/mcp`를 MCP 클라이언트에 등록합니다. 이미지 생성·편집과 결과 조회, 에셋 제작도 UI와 같은 작업 큐를 사용합니다. 요청별 생성 지침은 저장 설정을 변경하지 않습니다. 호출 예시와 연결 안내는 [MCP 사용법](Docs/Mcp.md)을 참고하세요.

## 기술 방향

- **언어·런타임**: C# / .NET 10
- **현재 배포 플랫폼**: Windows x64
- **UI**: Avalonia
- **생성 방식**: ComfyUI 또는 설치된 Codex

프로젝트 구조와 저장 책임은 [아키텍처](Docs/EidolonArchitecture.md), 개발 문서는 [Docs](Docs/README.md), 변경 기준은 [작업 규칙](Docs/WorkingRules.md)에 정리했습니다.

## 데이터 생성과 배포

문자열 원본은 `Excel/String.xlsx`입니다. ExcelToJson과 JsonToCSharp로 런타임 데이터와 C# 템플릿을 생성합니다. Debug 실행은 출력 폴더의 JSON을 먼저 읽고 Release 배포는 EXE에 포함한 JSON을 사용합니다. 절차는 [문자열 데이터 변환](Docs/StringData.md)을 따릅니다.

Windows x64 자체 포함 단일 EXE는 다음 명령으로 만듭니다.

```powershell
dotnet publish Eidolon.App/Eidolon.App.csproj -p:PublishProfile=WindowsX64 -o artifacts\win-x64 -m:1 /p:UseSharedCompilation=false
```

런타임과 UI·문자열·고지 리소스는 EXE에 포함합니다. 생성·학습 엔진과 가중치는 선택한 설치 경로에 별도로 준비합니다. 공개 베타는 배포 파일을 생성해 게시하며 별도 자동 테스트·배포 EXE 실행 검증은 수행하지 않았습니다.

## 외부 구성요소

UI는 Avalonia, 로컬 생성은 ComfyUI, 학습은 sd-scripts를 사용합니다. 기본 모델과 추가 가중치에는 각각의 배포 조건이 적용됩니다. 라이선스와 버전, 설치 시 전달하는 고지는 [외부 소프트웨어 고지](Docs/ThirdPartyNotices.md)를 참고하세요.
